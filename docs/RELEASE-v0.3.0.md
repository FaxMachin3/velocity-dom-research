# v0.3.0 — minimal-move keyed rendering research preview

Adds a reusable keyed-list reconciler with prefix/suffix matching and longest-increasing-subsequence movement, plus selected JS, optional Wasm, and clone-control adapters. The suite now includes 13 adapters and 20 workloads. The selected renderer uses retained text nodes, delegated events, snapshot fast paths, whole-list clearing, and focus restoration.

## Findings and tradeoffs

The supplied frozen-build experiment contains 10,400 operation measurements over two normal batches and one throttled batch, with zero recorded output failures. These are separate author-run batches on the same environment, not external independent reproduction. Earlier selection iterations, rejected batch-HTML code, and historical v0.1/v0.2 results are retained separately.

The distant swap uses two DOM insertions rather than 997 in the prior renderer. Swap and rotation latency gains repeat across all three final batches. Clear and sparse/full-row updates improve, while JS replacement regresses across all three batches; throttled append/shuffle also regress. The clone control wins some cases. No universal performance lead is claimed.

The supplied planner-only 100k-entry median is approximately 13.8% lower for Wasm, while smaller inputs show no useful advantage. Common list fast paths can bypass the planner. Wasm remains optional and has a larger delivery footprint. The selected JS fixture is 6,624 raw bytes; the Wasm fixture totals 26,555 JS+Wasm raw bytes. Fixture sizes are not feature-equivalent framework comparisons.

## Scope and verification

The optimized adapter is manually specialized to the fixture; it is not generated by the original compiler. Inputs require immutable snapshots and unique u32 IDs. Arbitrary keys, duplicate-key handling, row-resource disposal hooks, a complete component model, SSR/hydration, and production accessibility guarantees remain out of scope.

New checks exercise seeded update sequences, escaping and edge-case text, retained identity/focus, two-move swaps, and repeated remounts. The supplied timing evidence is Chromium-only. Release correctness checks on other browsers do not establish their performance. No peer review or external independent performance validation is claimed.

Publication preserves supplied timing files rather than rerunning or pooling benchmarks. Research/citation metadata is updated for this release. See results/DECISION.md, results/RELEASE.md, docs/V03_EXPERIMENT_PROTOCOL.md, and docs/V03_LIMITATIONS.md for full evidence and remaining regressions.
